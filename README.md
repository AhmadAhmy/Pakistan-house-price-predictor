# 🏡 PakProperty AI - Real Estate Price Predictor

PakProperty AI is an end-to-end Machine Learning web application designed to estimate property valuations across major Pakistani cities (Lahore, Karachi, Islamabad, Rawalpindi, and Faisalabad). The project addresses real-world machine learning challenges, including feature engineering, model size optimization for edge limits, API latency minimization, and seamless cloud deployment.
